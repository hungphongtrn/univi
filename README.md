# Univi

Univi is a research experiment on visual modality unification: render text as images, render audio as images, and use ordinary images unchanged so a single vision-language training path can consume all inputs visually.

The initial baseline target is `google/gemma-4-E2B`. The first planning risks are multi-turn context representation, dataset construction, feasibility under available compute, and novelty relative to DeepSeek-OCR, ImageBind, Unified-IO 2, and audio-tokenizer work.

See `CONTEXT.md` for the project language and `docs/RESEARCH_PLAN.md` for the current experiment plan.
