# Use Valor32k-AVQA v2.0 For The First Tri-Modal Cut

Univi will use Valor32k-AVQA v2.0 as the dataset of record for Phases 1-3 because it contains video, audio, and text QA in one public benchmark and labels each question as visual, audio, or audio-visual. This avoids stitching separate unimodal datasets for the first proof while still allowing controlled per-modality slices and image-only versus native-upper-bound comparisons.
