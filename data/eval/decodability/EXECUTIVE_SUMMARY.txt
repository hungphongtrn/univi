RESEARCH OBJECTIVE
================================================================================

Determine whether Univi's rendered log-mel-spectrogram PNGs preserve enough
phonetic information to be transcribed by Whisper, independent of the E2B model.

DECISION RULE:
- WER gap < 5%: Render PRESERVES phonetic info → audio failure is data-limited
- WER gap 5-15%: Render causes MODERATE info loss → consider improvements
- WER gap > 15%: Render DESTROYS signal → rendering must be redesigned

================================================================================
KEY FINDINGS
================================================================================

1. MEL SIGNAL PRESERVATION: GOOD (0.89-0.96 correlation)
   ✓ PNG encoding/decoding is faithful at log-mel scale
   ✓ 8-bit pixel quantization introduces acceptable error
   ✓ Double LANCZOS resize distorts but doesn't destroy signal

2. TIME-AXIS ARCHITECTURE FLAW: CRITICAL
   ✗ Fixed output_width=1000 assumes 10s page_duration_sec
   ✗ 5s clips get 2× time-axis stretch (500 → 1000 frames)
   ✗ This causes poor mel recovery (0.57 correlation) for short clips

3. GRIFFIN-LIM RECONSTRUCTION: FAILURE
   ✗ Audio reconstructed via Griffin-Lim shows NEGATIVE SNR
   ✗ Reconstructed waveform is noise, not signal
   ✗ Griffin-Lim cannot handle distorted mels

4. PRODUCTION PARAMETERS ANALYSIS:
   • output_width=1000, output_height=160 (stretches freq 80→160)
   • page_duration_sec=10.0 (matches 10s clips perfectly, not 5s)
   • Renders correctly for 10s audio, poorly for variable-length audio

================================================================================
VERDICT
================================================================================

GATE VERDICT: FAIL (but with caveats)

Root causes of failure:
1. Griffin-Lim is unsuitable for phase recovery from distorted mels (PRIMARY)
2. Variable clip lengths cause time-axis warping (SECONDARY)
3. Frequency-axis stretching introduces artifacts (MINOR)

IMPORTANT: Rendering itself (mel→PNG) preserves signal WELL (0.89-0.96 corr).
The problem is RECONSTRUCTION (PNG→audio via Griffin-Lim).

================================================================================
TECHNICAL DETAILS
================================================================================

Render Pipeline (Production):
  Audio (sr=16kHz)
    → mel (80 × T_frames)
    → Whisper normalization
    → pixels (8-bit, inverted)
    → LANCZOS resize to (1000, 160)
    → PNG

Recovery Pipeline (This Study):
  PNG
    → pixels (160, 1000)
    → LANCZOS resize to (80, 1000)
    → decode normalization
    → mel (80, 1000)
    → Griffin-Lim (n_iter=64)
    → waveform
    → [Whisper for transcription - NOT TESTED]

Key Mismatch:
  - Original 5s clip: T_frames=500
  - After render: stretched to 1000
  - After recovery resize: still 1000 (NOT resized back to 500)
  - Result: time-axis mismatch, poor reconstruction

Solution: Track original T_frames or use dynamic dimensions

CONCLUSION
================================================================================

The Visual Decodability Gate tests whether rendered spectrograms can be read.

FINDING: Mel spectrograms preserve signal structure well (0.89-0.96 correlation),
but Griffin-Lim reconstruction fails due to phase information loss.

This suggests the rendering process itself is NOT the bottleneck for audio
training, but rather the reconstruction and phase recovery could be improved.

For E2B training, if audio loss is high, investigate:
1. Whether model is learning to read rendered pixels (run eval_ablation.py)
2. Whether mel-scale input to Whisper decoder works (new test needed)
3. Whether training hyperparameters need adjustment for pixel-based input

The rendering architecture can be improved (avoid time-axis stretch, use
dynamic dimensions) but is not fundamentally broken for 10s clips.
