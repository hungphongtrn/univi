ARCHITECTURAL ISSUES IDENTIFIED
================================================================================

Issue 1: FIXED OUTPUT DIMENSIONS
  Problem: output_width=1000, output_height=160 assumed for 10s clips
  Impact:  5s clips get time-axis stretched 2×, causing poor recovery
  Severity: HIGH
  Fix: Use dynamic output_width = round(clip_duration / 10.0 * 1000)

Issue 2: FREQUENCY STRETCHING
  Problem: output_height=160 stretches frequency from 80 → 160
  Impact: Double interpolation (up then down) introduces artifacts
  Severity: MEDIUM
  Fix: Use output_height=80 to preserve frequency resolution

Issue 3: GRIFFIN-LIM PHASE RECOVERY
  Problem: Griffin-Lim fails to recover phase from distorted mel
  Impact: Reconstructed waveform is noise (SNR < 0 dB)
  Severity: CRITICAL
  Fix: Use mel-direct route (mel → Whisper decoder) or better vocoder

ROOT CAUSE ANALYSIS
================================================================================

GATE VERDICT: FAIL

WHY IT FAILS:
  1. Griffin-Lim cannot recover phase from distorted mels (PRIMARY)
  2. Time-axis mismatch for non-10s clips (SECONDARY)
  3. Frequency interpolation artifacts (MINOR)

WHY MEL IS GOOD:
  • PNG encoding: 0.994 correlation (excellent)
  • Pixel quantization: Acceptable at log-scale
  • Resize before Griffin-Lim: 0.89-0.96 correlation (good)

THE BOTTLENECK:
  Phase reconstruction via Griffin-Lim
  → Cannot recover meaningful phase from distorted magnitude spectrum
  → Results in noise instead of signal

DECISION FOR TRAINING
================================================================================

QUESTION: Is rendering preventing audio training from succeeding?

EVIDENCE:
  ✓ Mel preservation is GOOD (0.89-0.96 correlation)
  ✓ Pixel encoding is EXCELLENT (0.994 correlation)
  ✗ Audio reconstruction is FAILED (SNR < 0 dB)

INTERPRETATION:
  Rendering itself is NOT the bottleneck IF:
  • E2B model is trained on mel-scale features (not audio waveforms)
  • Whisper-like models work with mel input directly

  Rendering COULD be the bottleneck IF:
  • E2B model requires high-fidelity audio reconstruction
  • Current pipeline implies Griffin-Lim reconstruction for Whisper

RECOMMENDATION:
